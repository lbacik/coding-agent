# Add `slugify` to the fixture package

Add a `slugify(text: str) -> str` function in a new module `l2_fixture_py.text` that turns a human-written title into a URL slug.

The seam is the public function `l2_fixture_py.text.slugify`.

## Acceptance criteria

- [ ] `slugify("Hello, World!")` returns `"hello-world"`.
- [ ] Runs of whitespace, punctuation and hyphens collapse into a single `-`, so `slugify("a  --  b")` returns `"a-b"`.
- [ ] Leading and trailing separators are stripped, so `slugify("  -Hi-  ")` returns `"hi"`.
