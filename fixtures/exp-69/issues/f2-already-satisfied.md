## What is asked for

A user reported that `shout` upper-cases only the name and leaves the rest of the greeting as
it is. The whole greeting should be upper-cased.

## Acceptance criteria

- [ ] `shout` returns the entire greeting in upper case: `shout("world")` returns
  `"HELLO, WORLD!"`.
- [ ] `greet` keeps its current behaviour: `greet("World")` returns `"Hello, World!"`.

## Out of scope

Any new argument, any change to `greet`, and any other formatting of the greeting.
