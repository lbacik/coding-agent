## What is asked for

The greeting module should be able to say goodbye as well as hello.

## Acceptance criteria

- [ ] `farewell(name)` returns `"Goodbye, <name>!"`: `farewell("World")` returns
  `"Goodbye, World!"`.
- [ ] `farewell` is importable from `l2_fixture_py.greeting`, next to `greet` and `shout`.
- [ ] `greet` and `shout` keep their current behaviour.

## Out of scope

A shouted farewell, localisation and any change to the existing functions.
