## Summary

Implemented most of the "mirror run progress to container log" feature (uncommitted work on branch `agent/issue-503`). New shared module `src/coding_agent/operator/runlog.py` provides a process-wide print lock, `run:` line formatting (`run: [<attempt_id>] <text>` for Attempt-scoped, `run: <text>` otherwise), stderr routing for `halted`/error-level, a per-connection pending-event queue (queue on emit, flush after commit, discard on rollback), and `CODING_AGENT_LOG_TURNS` switch. Wired printing after commit at: `RunLedger._emit_lifecycle_event` (covers claim/phase/outcome/finished/released/sealed + all native step events), `RunLedger.emit_contract_event`, both `record_halt` recorders (ledger + operator store), `OperatorStore.emit_startup_event`, and the command-event path (`_emit_command_event` now returns and queues the record; flush/discard added in ledger `set_attempt_state`/`confirm_priority_claim`/`release_priority_claim`/`reconcile_accepted_commands`/`resolve_next_command` and in listener `_serve_mutation`/`_serve_next_issue`). `TranscriptModel.invoke` now prints per-turn lines (tool names only, usage suffix, per-conversation turn counter, redacted, stdout, gated by env var) plus a failure line. End-of-Attempt line in `worker/attempt_run.py` extended with spend suffix (`tokens= cost_usd= tool_calls= elapsed=`) reusing `spend_from_executions` + `attempt_opened_at`.
