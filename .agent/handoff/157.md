### Design decisions

- Graph `gate` overrides any pre-Intent outcome on cancellation; the
  Delivery Intent is still ahead there, so everything at `gate` is
  pre-Intent. `delivery_snapshot` still commits+pushes for every outcome.
  After the Intent nothing re-reads state, so P-CAN-2 holds structurally
  (`publish` has no Gate check).
- Fake default (no candidate held) is open+labeled, so existing scripted
  Attempts pass every Gate. `read_issue_state` is in fake `_READS`,
  preserving the M1 ordering proof.
