(`w2/state/mirrors/...`) does not exist yet — `ensure_mirror` runs only
post-claim in `run_attempt` — so intake `verify_offer_remote` fails at
`is_ancestor` in the nonexistent mirror (ls-remote succeeds, mirror read
raises → caught → False → `pickup-unavailable`), and selection finds
nothing because finalisation removed the Selection label (issues carry only
`round-finished`). Proven empirically: a debug replay shows both offers
eligible (`pickup_exclusion=None`) and both verify `True` against a real
mirror. So the fix belongs in production code (ensure/update the mirror
before intake verification, e.g. in startup or in the pickup verifier),
not in the test.
