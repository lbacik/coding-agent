## Migration pattern used (repeat for remaining files)

- Value: `AttemptMarker(attempt=..., kind=..., step=..., execution_number=..., ordinal=...)`;
  claim markers via `claim_marker_for(attempt)`, terminal via `terminal_marker_for(attempt)`.
- Text: `format_attempt_marker(value)` (`coding_agent.inputs.github`); claim bodies via
  `claim_comment_body(attempt, key, format_attempt_marker(marker))`.
- Ports take the value: `post_comment(n, t, body, marker)`, `post_claim_comment(n, t, body, marker)`,
  `publish_review(n, commit_id=..., body=..., marker=...)`,
  `open_pull_request(..., body=..., draft=..., marker=...)`, `find_*(..., marker)`.
- `render_terminal_comment` requires `marker_text=`; tests use
  `support.markers.terminal_marker_text/claim_marker_text`.
- Trust helpers (`trusted_terminal_attempt_ids`, `has_trusted_terminal_comment`,
  `newest_pickup_offer`, `in_force_claim_comments`, `winning_claim`) accept optional
  `format_marker` (GitHub fallback); production passes `inputs.format_marker`.
