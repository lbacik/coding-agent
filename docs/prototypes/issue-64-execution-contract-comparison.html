Does explicit activation make an Attempt more observable?

This comparison lets a decision owner run the same bounded Attempt traces through the current eager-injection control and the proposed activation contract. It asks whether the proposed state machine makes completion, evidence, handoff, and review provenance observable without weakening the runtime-owned guarantees.

Comparison criteria set before use: retain only a design that (1) does not treat silence as completion, (2) forces activate_implement for every fresh work node, (3) keeps skill bodies out of durable handoff state, (4) accepts only runtime-owned criterion evidence, and (5) surfaces review freshness without making review an unconditional Publication Gate. The traces are scripted, bounded fixtures—not evidence of general model reliability. Token and time figures are fixture values, not paid-provider measurements.
